webpack打包avalon2.0项目

发表于 2016-09-08 更新于 2026-09-09 分类于 前端自动化 阅读次数：

最近项目需要做一个小巧的web应用，所以用了avalon，并用webpack管理代码

安装过程就不在赘述，可以看webpack的安装

  1. 安装webpack
  2. 新建项目目录
  1. 使用 npm init 新建一个package.json来管理依赖
  1. 配置webpack
  1. 使用
    在index.html 引用 /dist/index.js

编写index.js,需要哪个就require进来

  1. 编写完成后，在终端进入到项目路径下，执行打包指令webapck

  2. 启动webpack-dev-server,访问http://localhost:8080/webpack-dev-server/index.html

现在已经成功打包了avalon

配置文件详解

配置文件中的loader，用来将各种文件一起打包在一起，css,js,scss,html等文件打包到一起
